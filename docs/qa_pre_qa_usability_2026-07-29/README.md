## Campaign files

Defect status such as `Fixed locally; final regression pending` means the implementation and focused proof exist, but no final-SHA campaign pass, queue rescan, or release verdict is being claimed. Each implemented ledger entry records the primary fix commit; later metadata-only evidence commits do not rewrite that ownership.

- `GC-USAB-*` identifies a product defect.
- `GC-HARNESS-*` identifies a verification defect or false-green risk; correcting one is not a product repair.
- `GC-ENV-*` identifies an external or ambient environment condition; it cannot be converted into a product pass.
