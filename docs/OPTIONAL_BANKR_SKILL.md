# Optional Bankr Skill

The built-in Bankr flow is disabled in the public GoatCitadel workspace by default.

If you want that behavior, install the optional skill pack from [templates/skills/bankr-optional/SKILL.md](../templates/skills/bankr-optional/SKILL.md) into your local skill environment and enable it through your normal skill-loading workflow.

This document stays public because the runtime and UI reference it when explaining why the optional capability is unavailable by default.
