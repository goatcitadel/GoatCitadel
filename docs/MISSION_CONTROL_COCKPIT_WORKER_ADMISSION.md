# Cockpit completion: local delegation and remote-worker admission

Source and focused-test checkpoint: 2026-09-30. This note separates verified local admission from the remaining remote-worker limitation. It does not change runtime policy, test expectations, or release gates.

## Local supervised children: implemented and directly verified

An operator can now accept a standard local delegation from a real admitted Chat parent through the existing public `delegate/suggest` and `delegate/accept` APIs. The parent and child use ordinary durable Chat authority. This path does not create a frozen capability profile or retained remote-worker context.

The exception is limited to explicitly supervised local children. Automatic fanout, workspace exploration, routed context, workspace snapshots, model council, and remote placement have not acquired new authority.

| Current source owner | Binding and responsibility |
| --- | --- |
| `chat-delegation-service.ts`: `ChatDelegationService.runChatDelegation` | Retains the existing dispatch claim and deterministic child identity. The local child callback binds the durable run, exact child turn, and required watcher inside durable admission. Presentation callbacks run after commit. |
| `chat-local-delegation-authority.ts`: `assertLocalDelegationTurnAuthority` | Requires a real parent Chat admission binding, matching parent/child operator identity, current session incarnations, exact workspace/task/delegation/step lineage, and a current initial dispatch claim or exact durable replay claim. Unbound or foreign records fail closed. |
| `chat-turn-prep-service.ts`: `prepareAgentChatTurn` | Revalidates the local child against that owner. The existing historical-profile and unsupported-context checks remain separate. |
| `chat-turn-dispatch-service.ts`: `launchPreparedAgentChatTurnStream` | Revalidates local child authority inside the admission transaction before invoking the canonical linkage callback. |
| `chat-durable-run-service.ts`: `beginDurableChatRun` | Requires atomic linkage for this profile-free delegated path. The linkage commits with the durable admission before processing is requested; a failed linkage cannot publish or schedule a child. |

The worker therefore remains ineligible for a newly admitted ordinary Chat turn even when native enrollment, transport, budgets, and tool grants are otherwise valid.
