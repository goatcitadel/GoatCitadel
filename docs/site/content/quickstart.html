Install on Windows

Open the GoatCitadel releases and pick the Windows installer for your machine. Use x64 for Intel or AMD PCs and ARM64 for Windows on Arm. Check the release notes and verify the published SHA-256 before running an installer.

Open GoatCitadel from the Start menu after setup. Mission Control opens your local workspace. For developer and container setups, see Install GoatCitadel.

Choose a model

Follow the first-run setup to choose a model and set your safety preferences. Connect a cloud provider you already use or point GoatCitadel to a local model server. You can change the choice later under Settings › Models.

See Model providers for the connection details each option needs.

Send your first message

  1. Open Chat and confirm the selected model in the composer.
  2. Send a simple request, such as Give me three ideas for organizing meeting notes.
  3. Wait for the reply. A completed answer confirms the selected model can respond. If it fails, check the connection in Settings › Models or follow the model troubleshooting steps.
