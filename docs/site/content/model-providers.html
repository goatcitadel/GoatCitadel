Connect a cloud provider

  1. Open Settings › Models and select a provider in the guided setup.
  2. Follow the provider's supported sign-in or credential flow. Enter API keys in provider settings.
  3. Choose a model for Chat and send a short prompt to verify that it replies.

Cloud providers receive the request and the context sent with it. Review the selected provider and model before sending sensitive material.

Connect a local model

Start a supported local model runtime such as llama.cpp, Ollama, or LM Studio. In Settings › Models, use Local AI or a compatible provider endpoint as appropriate. Use the base URL and model identifier reported by your runtime.

The address must be reachable from the Gateway. If GoatCitadel runs in a container, the container's loopback address refers to the container itself. See the llama.cpp setup guide for the managed local setup.

Check the selected model

Check the Chat model selector before sending a request. Inspect the reply's available details to see which provider and model actually ran. Review model routing and fallback in Settings › Models if it used a different one.

If no reply arrives, see Model does not reply.
