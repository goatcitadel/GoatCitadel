Chat

Start here for questions, drafting, research, planning, and coding. Use the composer to choose a model and attach context. Review tool results, approval requests, and generated artifacts in the conversation.

Open Chat › Messaging to configure supported messaging channels. Channel setup is documented in the messaging channel guide.

Inbox and Work

Inbox is where you resolve decisions waiting on you and inspect decision history. Open the related run to confirm the effect of an approval. Work shows tasks, runs, and schedules so you can follow work across conversations.

Capabilities and Library

Capabilities is where you configure connectors, tools, skills, and plugins. Library holds memory, notes, files, artifacts, and knowledge sources.

System and Settings

Open System for health, usage, backups, and diagnostics. Use Settings for provider connections, safety rules, workspace setup, and access controls.

In Mission Control, press Ctrl or ⌘ with K to open the command palette and jump to an area.
