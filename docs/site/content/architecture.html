Gateway

The Fastify Gateway owns routing, tool policy, approvals, memory, provider connections, and durable execution. It records decisions and run outcomes in storage and sends realtime updates as work progresses.

Mission Control

Mission Control requests state and actions through Gateway APIs. Chat is the entry point for conversation, agentic work, and governed code execution. Work and Inbox show run and decision records from that same runtime.

Models and tools

The provider layer routes model requests to the configured cloud or local runtime. The capability system keeps the catalog you can inspect separate from the tools and skills the assistant can call. The Gateway checks current policy, approvals, and scope before executing an action.

Code Mode runs trusted code with explicit approval and records the artifact used for execution. Run only code you trust.

Runtime records

A session holds turns. A durable run tracks resumable execution. An approval records a decision and can link to the run it governs. Realtime events notify Mission Control about changes, and the underlying records preserve the outcome.
