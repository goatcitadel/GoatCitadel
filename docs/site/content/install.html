Windows installer

  1. Download GoatCitadel-Setup-windows-x64.exe or GoatCitadel-Setup-windows-arm64.exe from the release assets for your architecture.
  2. Compare the file's SHA-256 to the checksum published for that release. The release notes describe signing status and any preview limitations.
  3. Run the installer, launch GoatCitadel, and follow the first-run setup.

Run from source

Use a source checkout for development. Install Git, Node.js 22 or later, and Corepack first. Use the pnpm version pinned in the checkout's package.json.

The default source setup serves Mission Control on localhost:5173 and Gateway health on 127.0.0.1:8787/health.

Run with Docker Compose

From a source checkout with the pnpm dependencies installed, generate Docker credentials and start Compose. Use these commands for a fresh Compose environment. Preserve an existing .env and consult the setup guide when upgrading.

Open localhost:4173 for Mission Control. Compose binds its published ports to loopback by default. Review authentication, allowed origins, and the bind address before sharing the deployment.

Platform support

Windows has packaged x64 and ARM64 installers. macOS ARM64 packaging and the Linux x64 release bundle are experimental. Check the platform support matrix and the install and setup guide for requirements and release-specific details.
