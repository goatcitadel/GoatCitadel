Connect a service

Open Capabilities › Connectors, choose the service, and follow its connection instructions. Use Advanced setup for integration connections, MCP servers, and web search credentials. Review requested access before enabling an action.

Manage tools and skills

Use Capabilities › Tools to inspect or restrict tool groups. In Capabilities › Skills, review a skill's source, then enable, pause, or switch it off. Review and approval govern imported skills before they become callable.

A skill supplies instructions for a task. Its tool calls still need the same policy and approvals as calls from Chat. See Approvals.

Install a plugin

In Capabilities › Plugins, review the proposed bundle and its trust label before approving installation. Follow any separate activation or connection steps shown for the pieces you want to use.

See the Plugin SDK for the manifest, supported piece types, and preflight validation.
