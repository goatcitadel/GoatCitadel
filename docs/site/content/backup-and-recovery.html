Create a backup

Open System › Health and choose Back up now. Create a fresh backup before an upgrade or maintenance, then copy the archive to a separate storage location.

Where the GoatCitadel CLI is available, list backups with:

Verify the archive

Replace <backup-file> with the path to your archive. For a current backup, check both verified for archive integrity and contractVerified for the required data.

Restore offline

Keep a verified copy of your current profile before restoring. For a filesystem-backed runtime, stop the Gateway serving the target runtime root and follow the offline CLI restore steps. For PostgreSQL, follow the separate operator-run pg_restore workflow.

Use the procedure for your storage type in the installation and recovery guide and check the backup contract for what the archive covers.
