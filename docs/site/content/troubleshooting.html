Mission Control cannot connect

Check System › Health for the Gateway and database. For a source or default Compose setup, check the local health endpoint from the machine running the Gateway:

If the Gateway responds and Mission Control still rejects the connection, check the configured Gateway address and credentials under Settings › Access. See the installation troubleshooting guide for port conflicts and launcher issues.

Model does not reply

  1. Confirm the chosen provider and model in the Chat composer.
  2. Review sign-in, credentials, or the local endpoint in Settings › Models.
  3. Check provider quota or budget if the error points there, then send a short test prompt.

See Model providers for connection setup.

An action is waiting

Check the conversation and Inbox for a pending approval. After deciding, open Work or the linked run for the recorded outcome and any recovery step. See Approvals.

Report a problem

Include your GoatCitadel version, platform, the steps that triggered the problem, and the relevant error. Remove credentials and personal data from logs before sharing them. Search for an existing report or open a GitHub issue.
