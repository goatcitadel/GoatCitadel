Plugin manifest

A GoatCitadel plugin is a declarative bundle. Put goatcitadel-plugin.json at the root of the plugin folder. List its pieces in the manifest and keep their paths inside the folder.

  • Skill · instructions in a folder containing SKILL.md.
  • Connector · a reference to a supported connector template.
  • Tool group hold · holds a tool group off for the life of the install.
  • Hook · observes a supported event.
  • Prompt pack · a Markdown file.

Use the schema and restrictions in the Extensions SDK contract.

Validate the bundle

The published @goatcitadel/extensions-sdk 1.0.0 package provides effective-tool snapshot helpers. The workspace's 2.0.0 adds parsePluginManifest, loadPluginManifest, and the preflight command. Use a workspace build of 2.0.0 for the new tooling.

With the workspace command on your path, pass the plugin folder. A successful check reports the plugin ID and the manifest hash.

Review and install

Open Capabilities › Plugins to inspect the bundle and review its Change Plan. Check the trust label, Built in or Unverified, and the requested pieces before applying it. Keep authorization for activated skills and connected accounts scoped to your intended use.
