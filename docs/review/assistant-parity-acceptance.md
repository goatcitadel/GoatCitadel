## Defaults, governance and rollback

- Memory administration defaults on only when no explicit preference exists; preserve stored off settings. Indexed corpus recall, background skill drafts, maintenance and skill-instruction use keep their independent opt-in flags.
- Background memory/skills/maintenance remain proposal-only. Installation-wide setup is visibly reviewed; source/candidate/version hashes, current scope and policy remain mandatory at apply.
- Forget/revoke stops fresh use; retained audit and immutable historical context remain historical evidence.
- Disable the corresponding feature flag to stop new dispatch/admission. Do not delete journals or roll back additive migrations. Revoke approved skill use or forget exact memory through its owner. Unknown dispatched work remains awaiting reconciliation; do not refund or replay it as though it never happened.
- Regression recovery uses the recorded pre-activation snapshot and canonical paused state. Operator rollback is a distinct action.
