# Reference Integration Plugin

This packaged copy keeps the extension SDK distribution artifact aligned with the repo reference scaffold.

The manifest is intentionally data-only. Runtime install/enable smoke evidence must still come from GoatCitadel verification lanes before broader extension claims are made.

The optional `configurationForm` demonstrates typed non-secret defaults, a
credential-reference requirement and a sample-task description. It contains no
credential value and performs no configuration or tool invocation. Run
`goatcitadel-extension-preflight LOCAL_SOURCE` to validate its author metadata;
a passing result is not runtime verification.
