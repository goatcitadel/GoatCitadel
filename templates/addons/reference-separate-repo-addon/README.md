# Reference Separate-Repo Add-on

This scaffold is the current in-repo example for GoatCitadel add-on authors.

Files:

- `goatcitadel.addon.json`: author-manifest example that matches the repo's current add-on contract validation.

Use this scaffold when:

- building a separate-repo add-on
- documenting install/build/launch expectations
- defining trust, provenance, and runtime health honestly

Before using it for a real add-on:

- replace placeholder repo URLs
- replace placeholder install commands
- replace placeholder launch URL and port
- update health checks to match the real runtime behavior
