Design Review · 2026‑05‑15

Tightening Mission Control Next.

The current build is functionally complete and stylistically restrained — but the visual system is doing less work than it could. Hierarchy collapses inside the 12px density, area color reads as a single rail pixel instead of wayfinding, and the 13‑section Settings IA fragments configuration. This review proposes a tighter typographic ladder, a more confident application of area accent, a 4‑group Settings consolidation, and a few surface‑specific moves on the threaded timeline, approvals, and prompt packs. Eight responsive mockups follow, each annotated.

01

Type scale earns its keep

Lift body from 12 → 13px, headings to 22/18/15/13, and reserve mono for IDs, hashes, and tabular numerics. Same physical density, far better hierarchy.

02

Area color as wayfinding

Each route family already owns an OKLch accent. Promote it from a single rail‑link tint to a 2px stage stripe + tinted eyebrow + scoped chip wash. Glanceable from any tab.

03

Status density, not status soup

Replace mixed pill flavors with a three‑part chip: Streaming42s — state, dot, and a mono age. Reads at a glance in the timeline and runtime feed.

04

Settings 13 → 4 groups

Group into Foundations · Identity · Surfaces · Operations. Keeps every leaf reachable in one rail page on a laptop, and lets the General overview do real summarisation.

05

Composer that knows its context

A persistent strip above the textarea showing model, mode, attached files, and live token/$$ — without stealing vertical from the prompt area. One affordance per mode (Send / Delegate / Implement).

06

Approvals: evidence first, decision second

Lead each queue card with the artifact under decision — trace + diff + affected service — then the approve/reject/replay row. Bulk reject moves to the toolbar with confirm.
